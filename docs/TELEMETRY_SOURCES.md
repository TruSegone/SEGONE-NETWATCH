# Telemetry sources

Currently supported source: deterministic synthetic demo fixtures only. They are marked `demo` and fictional. Authenticated normalized-event ingestion is an API interface, not a collector implementation. No interface enumeration or packet capture is claimed.

Windows packet visibility depends on the NIC, driver/backend, capture permissions, wireless mode, and access point. Ordinary Wi-Fi client mode generally does not expose every other station's traffic. A router or DNS resolver log adapter is a future option for authorized monitoring.
